# Grupo CPOnet — Web frontend

Proyecto frontend estático construido con HTML, CSS y JavaScript vanilla.

## Estructura
- `index.html`: Home
- `pages/`: páginas internas
- `css/`: estilos separados por responsabilidad
- `js/`: navegación, animaciones, eventos y formulario
- `assets/`: espacio para imágenes, logos, iconos y fuentes

## Funcionalidades incluidas
- Header transparente que cambia al hacer scroll
- Menú responsive
- Navegación suave
- Animaciones al entrar en viewport
- Filtro de eventos
- Selector interactivo de niveles GBN
- Validación de formulario
- Responsive para móvil/tablet/desktop

## Importante
El formulario actualmente muestra una confirmación en frontend. Para producción debe conectarse a un backend/API o servicio de correo.

Las fotografías utilizadas son imágenes de demostración externas. Para producción deben sustituirse por material autorizado de Grupo CPOnet.
